What is a Regular Expression?

A regular expression (also called regex) is a sequence of characters that defines a search pattern. They are used to match and manipulate text.

Common uses: - Cleaning messy data (removing symbols, fixing formats) - Extracting structured info from text (emails, dates, phone numbers) - Feature engineering (hashtags, mentions, sentiment cues) - Web scraping and log parsing - Data validation for preprocessing pipelines

Examples

  • [a-z]+ — matches any sequence of one or more lowercase letters
  • \d{3}-\d{2}-\d{4} — matches a number (e.g., SSN) in format 123-45-6789
  • ^https?:// — matches beginning of a URL (http or https)
  • [aeiouyAEIOUY] — matches any vowel (and y)

Character Classes

Specified using [ ] — groups of characters that satisfy the search.

Ranges: [a-zA-Z] matches any letter. Metacharacters (except \) are not active inside classes, so [akm$] matches "a", "k", "m", "$".

If ^ is the first character in a class, it means complement: [^aeiou] matches anything except lowercase vowels.

The Backslash \

The backslash \ signals special sequences and is used to escape metacharacters.

It can even escape itself: \\ searches for \.

Anchors

Anchor Meaning Pattern Matches / Not
^ Start of string ^Hello “Hello world” ✓, “Say Hello” ✗
$ End of string world$ “Hello world” ✓, “worldwide” ✗
\b Word boundary \bcat\b “cat” ✓, “concatenate” ✗
\B Non-word boundary \Bcat\B “concatenate” ✓, “cat” ✗

Anchors, continued

  • \A — matches only at the start of string
  • \Z — matches only at the end of string
  • \b — word boundary

\b can interfere with Python’s string literals. Use raw string literals with r, e.g., r"\d+.\d?".

Read & Decipher (Simple) — Hints

Think about what each piece means: - \b = word boundary - \d{5} = exactly five digits - ^[A-Z] = starts with an uppercase letter - [a-z]+ = one or more lowercase letters - $ = end of string

Read & Decipher (Simple) — Solutions

  1. \bcat\b — matches the whole word cat
  2. \b\d{5}\b — matches a 5-digit token (US ZIP code)
  3. ^[A-Z][a-z]+$ — matches a capitalized word (e.g., Kerby)

All three target different kinds of “words” in text.

Read & Decipher (Medium) — Solutions

  1. ^\s*\#.*$ — matches comment lines (optional leading spaces, a #, then anything to end of line)
  2. https?://[^\s)]+ — matches a simple URL starting with http or https, continuing until a space or ).

How Would You Extract Phone Numbers?

Task: Find all U.S. phone numbers 123-456-7890 in text.

Hints: \d means digit, {n} means exactly n times.

Solution on the next slide.

Extract Phone Numbers — Solution

import re

text = "Call 801-555-1234 or 212-999-8888 today!"
pattern = r"\b\d{3}-\d{3}-\d{4}\b"
print(re.findall(pattern, text))
# ['801-555-1234', '212-999-8888']

The \b anchors ensure we don’t grab digits embedded in longer numbers.

How Would You Extract Email Addresses?

Task: Identify all email addresses in text.

Hints: Start with word characters before @, match the domain, use + for one or more.

Solution on the next slide.

Extract Email Addresses — Solution

import re

text = "Contact us at help@university.edu"
pattern = r"\b\w+@\w+\.\w+\b"
print(re.findall(pattern, text))
# ['help@university.edu']

\w+ matches one or more word characters — the local part and the domain.

Python re Library — Matching

Function Returns
re.findall(pattern, string) All matching substrings as a list
re.match(pattern, string) Matches at the beginning of the string
re.search(pattern, string) Finds the first match anywhere
re.finditer(pattern, string) Iterator of match objects
re.compile(pattern) Compiles a pattern for repeated use

Python re Library — Modifying Strings

Function Description
re.split(pattern, string) Splits the string where the RE matches
re.sub(pattern, replace, string) Replaces matches with replace
re.subn(pattern, replace, string) Same as sub, but returns a (result, count) tuple

re Isn’t Always Necessary

Python’s built-in string methods often do the job:

.endswith() · .startswith() · .join() · .find() · .replace() · .strip() · .rstrip() · .lstrip() · .strip('#') · .split() · .lower() · .upper()

Applying to Pandas

  • Use the .str attribute for vectorized string operations.
  • Use the .apply() method with a lambda function for regex-powered logic.

Pandas Example

import pandas as pd
import re

data = {'text': ["Hello, World!",
                 "The rain in Spain",
                 "How are you?"]}
df = pd.DataFrame(data)

df['uppercase_text'] = df['text'].str.upper()
df['words_starting_with_S'] = df['text'].apply(
    lambda x: re.findall(r'\bS\w+', x)
)

.str.upper() needs no regex; .apply() with re.findall unlocks pattern power.
