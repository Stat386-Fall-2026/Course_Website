Which terminal are you using?

macOS

  • Open Terminal.
  • Your shell will usually be zsh.
  • Your home directory will look like /Users/yourname.

Windows

  • Open Git Bash.
  • Your shell will be bash.
  • Your home directory will look like /c/Users/yourname.

Your folders form a tree

/
├── Users
│   └── yourname
│       ├── Desktop
│       ├── Documents
│       └── Desktop
│           └── School
│               └── STAT_386
└── tmp
  • A path names a location in this tree.
  • ~ means your home directory.
  • Every command works from your current directory unless you give it another path.

Where am I? pwd

pwd means print working directory.

pwd

Run it now. The result tells you where the terminal is currently working.

What is here? ls

ls          # list visible files and folders
ls -l       # show details
ls -a       # include hidden items
ls -la      # combine both options

Hidden items usually begin with a period. You will always see . for the current folder and .. for its parent.

Moving between folders with cd

cd Documents  # enter Documents
cd ..         # move to the parent folder
cd ~          # return to your home folder
cd -          # switch to the previous folder

Type the first few letters of a folder and press Tab to finish its name.

Finding help

Most command-line tools provide built-in documentation.

git clone --help     # details and options for a Git command
git help clone       # another way to open Git help
man ls               # manual page on macOS
ls --help            # help text in Git Bash

Use the help text to discover options such as -a or -l. In a manual page, press q to quit.

Viewing a file

cat data/raw/scores.csv       # print the whole file
less data/raw/scores.csv      # view a longer file one screen at a time
wc -l data/raw/scores.csv     # count lines

In less, press q to return to the terminal.

Searching a file with grep

grep "Ada" data/raw/scores.csv     # matching lines
grep -n "a" data/raw/scores.csv    # include line numbers
grep -i "ada" data/raw/scores.csv  # ignore capitalization

grep finds lines that contain a pattern.

Copying and moving files

mkdir -p demo/copies
cp data/raw/scores.csv demo/copies/
mv demo/copies/scores.csv demo/copies/scores-backup.csv
ls demo/copies
  • cp creates a copy.
  • mv moves a file or changes its name.
  • Confirm a change with ls before continuing.

Wildcards with cp and mv

* matches any number of characters. The shell finds matching names before cp or mv runs.

mkdir -p demo/archive
cp notes/*.txt demo/archive/
mv demo/archive/*.txt demo/
ls demo

The two text files move from demo/archive/ into demo/.

Removing files carefully

rm permanently removes a file. There is no Trash or Undo step.

pwd
ls demo
rm demo/tasks.txt
ls demo

Pause before pressing Enter. Check your location with pwd and check the exact filename with ls. Do not use rm -r today.

Pipes connect small commands

A pipe, |, sends the text output of the command on the left to the command on the right.

grep -i "a" data/raw/scores.csv
grep -i "a" data/raw/scores.csv | wc -l

The first command prints matching rows. The second sends those rows to wc -l, which counts them.

Useful helpers:

  • head shows the first lines of a file.
  • tail shows the last lines of a file.
  • wc -l counts lines.

Saving command output

grep -E ',9[0-9]$' data/raw/scores.csv > demo/scores-in-the-90s.csv
cat demo/scores-in-the-90s.csv

This creates a new file containing rows with scores from 90 through 99. The pattern avoids treating a score such as 19 as a score in the 90s.

Warning: Choose a new output filename when using > unless you deliberately want to replace a file.

Opening the repository in Positron

From the top level of terminal-practice, run:

positron .

The period means “the current folder.” Positron opens the repository as a project, so its file explorer and terminal begin in the same place.

Vi survival card

You will normally edit files in Positron. On a remote computer, though, you may encounter vi.

vi notes/README.txt
  • i enters insert mode so you can type.
  • Esc returns to normal mode.
  • :wq saves and quits.
  • :q! quits without saving.

Tip: If vi feels unfamiliar today, that is fine. Keep this slide as an escape-and-save reference.

Takeaways

  • Your terminal always works from a current folder.
  • pwd, ls, and cd handle most navigation.
  • grep helps you inspect text and CSV files quickly.
  • Pipes let one command pass results to another.
  • git clone creates a local copy of your GitHub repository.
